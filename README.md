# PNL

Kişisel gelir / gider tablosu. Bilgisayarda büyük tablo, telefonda hızlı giriş ve görüntüleme.

## Telefonu bilgisayara bağlama

1. Bilgisayarda PNL'i aç → **Senkron** ile GitHub token'ını gir (bir kere).
2. **📱 Telefonu bağla** → çıkan QR'ı telefon kamerasıyla okut. Sayfa açılır ve bilgisayardaki veriyi alır.
3. Ana ekrana eklediysen (iPhone'da ana ekran uygulaması Safari'den ayrı depolama kullanır):
   bilgisayarda **Kodu kopyala** → telefonda **Ayarlar → Bağlantı kodu**na yapıştır.

## Telefonda kullanım

- **Özet**: seçili ayın sonunda elinde kalan, gelen / giden; altında 12 aylık şerit (dokun → o ay) ve yılın özeti.
  Kategori kartlarında her kalemin yanındaki **+** ile o kaleme ekle, kaleme dokunarak düzenle, sola kaydırarak bu aydan kaldır.
- **+** (ortadaki yeşil): yeni harcama / gelir. Kalem seç ya da yeni ad yaz; "Üstüne ekle" veya "Yerine yaz".
- **Tablo**: bilgisayardaki tablo, telefona sığan aylarla. Yana kaydırınca ay değişir, kategori satırına dokununca açılır / kapanır,
  "Sadece toplamlar" ile tek bakışta görünür. Tasarruf ve Bakiye altta hep görünür. Rakama dokun → düzenle.
- Her değişiklikten sonra **Geri al**. Sağ üstteki ayar düğmesi: senkron, yedek, görünüm.
